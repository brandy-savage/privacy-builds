# Security policy

Do not open an issue containing credentials, configured addon URLs, private
profile data, device identifiers, signing keys, or proprietary application
binaries. Redact logs before sharing them.

This repository documents experimental static hardening. It does not claim to
remove every telemetry path, guarantee anonymity, bypass service controls, or
preserve compatibility with vendor authentication and integrity checks.

Security reports should include the affected application/version, the smallest
reproduction possible, and a description of the privacy impact. Keep proof of
concepts bounded to software and accounts you own or are authorized to test.
